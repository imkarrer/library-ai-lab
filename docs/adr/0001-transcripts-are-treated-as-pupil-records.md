# Transcripts are treated as pupil records

In a Wisconsin school library, the operative rules are FERPA and Wis. Stat. 118.125 (pupil
records), not Wis. Stat. 43.30, which covers *public* libraries and is commonly conflated
with it. A transcript that can be tied to a Student is plausibly a pupil record, with parent
inspection rights and a 60-day response window. We design so that the assistant holds no
transcript tied to a Student and holds even pseudonymous transcripts only briefly (ADR-0002,
ADR-0003). COPPA does not reach a school-run, non-commercial Install, which is a structural
advantage over commercial chatbots for 11-to-13-year-olds; keep it that way by never adding a
commercial operator to the loop.
