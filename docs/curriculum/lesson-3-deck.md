# Catch it being wrong

<p class="lede">Lesson 3: audit an answer against real books.</p>

<p class="muted">Check the Source · 45 minutes</p>

## If every book is real, how could the answer still be wrong?

- The overview was written **before** the books were found.
- It can **sound sure** about a date, a name, or a cause and still be guessing.
- A book can be about the **topic** but not the **claim**.
- The **Record** can be thin, so you may need the book itself.

<p>Multi-step math especially. Check the steps yourself or in a book.</p>

## Four steps

<div class="steps">
<div class="card-panel"><strong>Question</strong><p>What does the answer claim? What might be
missing?</p></div>
<div class="card-panel"><strong>Check</strong><p>What evidence supports it? Which claims need
checking?</p></div>
<div class="card-panel"><strong>Compare</strong><p>Check it against reliable sources: the Record,
then the book.</p></div>
<div class="card-panel"><strong>Decide</strong><p>What is trustworthy, what needs fixing, what
shouldn't be used?</p></div>
</div>

<p class="muted">From Wisconsin DPI's Ethical Use in the Classroom guidance.</p>

---

## Three verdicts

<div class="cards">
<div class="card-panel">
<h3>✔ Checked</h3>
<p>A book backs it up.</p>
</div>
<div class="card-panel">
<h3>✘ Wrong</h3>
<p>A book contradicts it.</p>
</div>
<div class="card-panel">
<h3>○ Not in our books</h3>
<p>Nothing we own covers it, so it stays unchecked here.</p>
</div>
</div>

<div class="box">

"It's AI so it's probably wrong" is not a verdict. **Show the line** that contradicts it.

</div>
