        Technical details: Token hashes (for verifying against the server database by hand)

        Each Card's Token is hashed with SHA-256 on this machine, the same way the server hashes a Card at sign-in. These hashes are what Registration sent; the Tokens themselves never left this machine. The table is here only so a Teacher can cross-check a Card against the server's cards table if an upload ever needs confirming by hand.
